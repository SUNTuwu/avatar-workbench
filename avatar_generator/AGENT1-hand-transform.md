# Agent1 使用指南 · 手势缩放与位移

## 在工作台操作

1. 暂停在要编辑的时间，在「口型」面板举起目标手势。在「缩放框 → 手势」中选中它，勾选「在画面上拖」。
2. **拖框内**移动整只手。**拖左右边的中点**调宽，**拖上下边的中点**调高，**拖角**同时调宽和高。按住 **Shift 拖角**保留拖动开始时的宽高比例。
3. 锚点可以选「手腕」或「中心」。平移会带走锚点，所以移好位置后可继续原地缩放。需要精确值时，直接填「位移 X / Y」和「横向 / 竖向」。位移按手势局部像素计算，随角色转动。默认姿态下，X 向右，Y 向下。
4. 要做一段移动，在起点点「◇ 记关键帧」，跳到终点，拖到目标位置，再记一次。启用「自动记关键帧」后，改值或拖动会直接更新当前时间的关键帧。需要精确落点时，留意播放栏的「关键帧吸附」。
5. 拖时间轴检查运动轨迹，再到「关键帧 → 保存工程」下载 JSON。「显示框（会导出）」控制成片里的框线。只想导出手势动作时，留空即可。

「位移归零」只重置 X / Y，「缩放归 1」只重置宽高。展示手上的电脑随手平移，电脑尺寸仍由电脑自己的缩放参数控制。

## 在工程或蓝图中编辑

轨道名为 `hand.<手势 ID>`，ID 见 `rig.js` 的 `HANDS`。下面是「请看」手势的轨道片段，可以合并到现有 `tracks`。手势的出现和放下由原有事件控制。

```json
{
  "hand.palm": [
    { "t": 1.0, "v": { "x": 0, "y": 0, "sx": 1, "sy": 1, "anchor": "wrist", "box": 0 }, "ease": "ease" },
    { "t": 1.5, "v": { "x": 40, "y": -20, "sx": 1.2, "sy": 1.2, "anchor": "wrist", "box": 0 }, "ease": "ease" }
  ]
}
```

在默认姿态下，这段动画用半秒把手向右移 40、向上移 20 个局部像素，同时绕手腕放大至 1.2 倍。工程中的 `t` 是时间轴秒数，蓝图中的 `t` 是相对于片段起点的秒数。到达帧的 `ease` 决定这段过渡。旧帧缺少的 `x`、`y` 按 0 读取。
