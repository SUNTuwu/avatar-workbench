# 虚拟形象生成器

读 `../vtuber_art.psd`，用按钮/键盘实时切表情和动作，按配音自动对口型，导出透明 PNG 序列，拿去达芬奇和视频合轨。

## 打开

二选一：

- **推荐**：在这个文件夹运行 `powershell -ExecutionPolicy Bypass -File serve.ps1`，用 Edge/Chrome 打开 http://localhost:8765/ ，PSD 会自动载入。
- 直接双击 `index.html`，再把 `vtuber_art.psd` 拖进页面。

## 界面

右侧是 5 个选项卡，上次打开的会记住，Alt+1–5 可以直接切换：

| 选项卡 | 里面有什么 |
|---|---|
| 口型 | 载入配音、配音降噪、口型算法 / 灵敏度 / 降噪 / 防闪、麦克风、录一段 |
| 调节 / 动画 | 表情、嘴型、眼睛 / 耳朵 / 胡子、手势、电脑、动作、自动动画设置 |
| 输出 / 色彩 | 预览背景和参考视频、滤镜、曲线、导出 PNG 序列 |
| 关键帧 | 关键帧列表、撤销、清空、保存 / 载入工程 |
| 图层 | 载入 PSD、图层检查 |

## 做一条动画

1. **载入配音**：拖进 wav/mp3（建议从达芬奇导出整条配音轨，时间从 0 开始）。载入后会自动分析口型，时间轴上出现彩色口型条。
2. **试看**：直接点按钮或按键盘，效果马上出现，但这些按键**不会被导出**，左上角会显示「试看中」。
3. **录制**：勾上「录制按键」（或按 Enter），按空格播放，跟着配音按表情、动作。每次按键都会在当前时间记一个关键帧。暂停状态下按按钮，也会在当前时间点记关键帧，可以一帧一帧摆。
4. **修改**：在「关键帧」面板里改时间、删除，或者撤销上一个。点「保存工程」存成 json，下次拖进来接着改（先载音频再载工程）。
5. **导出**：设好范围，点「导出 PNG 序列」并选一个空文件夹。导出的文件夹里有：
   - `avatar_00000.png …`：透明背景的序列帧，达芬奇里可以直接当作一段素材导入
   - `转MOV_ProRes4444.cmd`：双击后转成带透明通道的 `avatar_prores4444.mov`，用的是系统里的 ffmpeg
   - `project.json`：这次的关键帧和口型，留给达芬奇 MCP 读

合轨的时候，把配音和这段动画放在同一个起点上就能对齐。

## 实时麦克风

麦克风只能在 serve.ps1 开的 `http://localhost:8765/` 页面里用，第一次会弹窗问权限。

- **开麦克风**（按钮或 M 键）：说话时嘴型实时跟着动，表情、动作按键照常用。旁边的小条是音量，颜色是当前口型。有多个麦克风时在下拉框里选。开头几秒在适应你的音量和音色，说几句就准了。
- **录一段**：时间轴从 0 开始走，这期间按的表情、动作自动记成关键帧（不用勾「录制按键」）。再点一次停止，录音会自动变成配音轨，并重新做一遍完整的口型分析。之后跟载入配音文件一样，可以回放、改关键帧、导出。
- **录音文件**：点「保存这段录音」可以单独下载 wav；导出 PNG 序列时，这段 wav 也会一起写进导出文件夹，拿去达芬奇当配音轨，和动画从同一个起点放就是对齐的。
- **口型的取舍**：录音时看到的是实时口型，大约晚 30–50ms；最终导出用的是停止后的离线分析，更稳、不会闪。
- **回放**：麦克风开着时，播放已有配音仍然按配音的口型；只有暂停或者在录音时，才跟麦克风走。
- **耳机**：录的时候建议戴耳机，避免喇叭的声音被录进去。浏览器的回声消除和自动增益已经关掉了，降噪保留开着。

## 降噪 / 嘴型闪

麦克风噪声大时有两处可以调，都在「1 素材」里：

- **口型降噪**（默认开）：分析口型前先估出噪声谱减掉，再用人声频段（250–4000Hz）的信噪比判断有没有在说话，风扇轰鸣、电流哼声基本不会让嘴乱动。实时的噪声每 1.5 秒自动重估，开麦后先安静一秒，状态栏显示「估噪中」时别说话。
  - **强度**：越大减得越狠，但人声小的字也可能被当成噪声。
  - **防闪**：越大嘴型越稳，但换口型会慢一点（默认约 90ms）。
  - **灵敏度**：说话时嘴不动（漏字）就往右拉；不说话时嘴还在动就往左拉。
- **配音降噪**：「降噪当前配音」把当前配音过一遍降噪（风扇、底噪、电流声这类持续的噪声），处理后的音频直接替换成配音轨，口型也重新分析；再点一次「还原原声」。「压低」是噪声最多压低多少 dB，默认 15，太大人声会发闷、有“水声”。勾着「录完自动降噪」时，麦克风录的每一段都会自动降噪。降噪后的 wav 可以保存，导出时也会写进导出文件夹。
  - 键盘声、说话声这类突发的声音减不掉。噪声特别大的话，还是建议先从硬件下手：麦克风增益调低一点、嘴离麦克风近一点、远离风扇。

用加了噪声的测试音频比过（噪声约为人声的 1/4）：不说话时嘴乱动从 100% 的时间降到约 11%，每秒换口型从 3.9 次降到 2.5 次；配音降噪后停顿处的噪声低了 15dB。

## 键盘

| 类别 | 按键 |
|---|---|
| 播放 / 暂停 | 空格 |
| 录制开关 | Enter |
| 麦克风开关 | M |
| 按住看调色前的原图 | \ |
| 表情 | 1 普通　2 震惊　3 星星眼　4 无语　5 得意　6 开心　7 闭眼　8 急急　9 馋　0 认真 |
| 嘴型（**按住**时覆盖自动口型，松开恢复） | a　o　e　i　u　b(bf)　n(普通)　z 流口水　x 波浪嘴　c 急急嘴；` 恢复自动 |
| 动作 | q 弹入　w 弹出　r 跳　t 连跳　j Q弹　y 点头　h 摇头　g 歪头　s 摇身　f 发抖　v 挥手 |

眼睛、耳朵、胡子、手势、电脑只能用鼠标点。

**手势和身体**：手势有展示手、竖手指、期待手、比心手。身体朝向跟着手势走，「期待手」会自动换成身体镜像版（图层 5），其他手势用正常身体（3/4 双层抖动），不用另外切。

**电脑**：电脑和「展示手」是分开的两样东西。电脑在手的左上方，画在手的前面，底边盖住手的后半边，像托在手上；默认位置不碰脸和胡子。因为电脑在角色左边，导出的「脚底 X」默认改成了 720。屏幕有三种：白屏、FINAL（屏幕上的字）、绿幕（纯绿 #00ff00，边缘保留了抗锯齿）。之后想在屏幕上放别的画面，就选绿幕导出，在达芬奇里抠掉绿色，再把画面垫在下面。电脑的位置和大小在「5 手势 / 道具」里调，会存进工程。旧工程里的「敲电脑」会读成「展示 + 白屏」，「FINAL 字」读成 FINAL 屏，旧的「身体偏移版」关键帧会被忽略。注意导出底色别选绿幕，不然整张图都是绿的。胡子默认一直显示（39/40 双层抖动），「急急」表情会自动换成炸毛胡子（41）。点嘴型按钮是「锁定」，要再点一次或者点「自动」才恢复。

## 口型规则

- 没说话时，用当前表情自带的嘴（比如「得意」是波浪嘴）
- 说话时用自动口型：信噪比判断有没有在说话，共振峰判断元音，映射到 a / o / e / i / u；刚停下的一小会儿算 bf（b/p/m 闭嘴）；s/sh/x 这类擦音（高频多）算 i（露牙）
- 手动选的嘴型优先级最高，会盖过上面两种
- 口型太碎或者太迟钝，就调「灵敏度」后点「重新分析口型」；声音很杂的时候可以改成「只看音量」

## 滤镜 / 曲线

只调虚拟形象这一层，不影响透明度。改动马上在预览里生效，勾着「导出时套用」时导出的 PNG 也会带上，存工程时会一起保存。

- **滤镜**：原图、鲜明（暖 / 冷）、戏剧（暖 / 冷）、单色、银色调、黑白、复古褪色、赛博。「戏剧」仿的是 iOS 的 Dramatic：压暗一点、加强中间调对比、降一点饱和度。iOS 的局部对比（类似“清晰度”）没有做。「滤镜强度」可以在原图和滤镜之间调。
- **曲线**：RGB / 红 / 绿 / 蓝四个通道，后面是当前画面的直方图。点空白处加点，拖动调整；双击、右键或者把点拖出框外就删掉；两端的点只能上下动。曲线叠在滤镜后面生效。
- **对比**：按住 `\` 键或者「按住对比」按钮，看调色前的原图。
- **参考视频也套用**：只影响预览里的参考视频，方便看虚拟形象和视频的色调搭不搭；视频本身还是在达芬奇里调。

## 自动的小动作

在「动画设置」里可以开关：双层线稿每秒交替 8 次（线稿抖动）、整体微抖、呼吸、自动眨眼（正常 / 星星眼 / 半睁这三种眼睛才会眨）、耳朵偶尔抖一下、说话时随音量轻晃头。导出时这些动作每次都一样，同一个工程导两遍结果相同。

「说话时随音量轻晃头」根据配音或麦克风的人声音量，轻微抬头和左右摆动，不追踪真人头部，也不识别语气。手动锁定嘴型时不触发。关闭后自动口型、手动动作以及独立的呼吸 / 轻微晃动仍正常生效。

## 图层对应

写在 `rig.js` 里，按 PSD 从下往上数的图层序号对应（组的起止标记也占一个号）。眼底和眼睛一一对应：13↔18、14↔19、15↔20、16↔21，22（笑眼）和 23（><）没有眼底。

**以后改了 PSD**：新增或调换了图层，打开页面最下面的「图层检查」看新序号，再改 `rig.js`。如果序号对不上，页面底部会有红字提示。

## 限制

- 只支持 8 位 RGB 的 PSD，不支持 PSB 和图层蒙版
- 口型分析不认字，只看声音；元音之间的过渡靠平滑处理，口型精确到大约 70ms
- 要选导出文件夹，得用 Edge 或 Chrome；别的浏览器会改成下载一个 zip
