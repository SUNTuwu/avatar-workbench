# 虚拟形象生成器

读 `../vtuber_art_new.psd`，用按钮/键盘实时切表情、手势和动作，按配音自动对口型，用骨骼关键帧摆姿势，导出透明 PNG 序列，拿去达芬奇和视频合轨。

## 打开

二选一：

- **推荐**：在这个文件夹运行 `powershell -ExecutionPolicy Bypass -File serve.ps1`，用 Edge/Chrome 打开 http://localhost:8765/ ，PSD 会自动载入。
- 直接双击 `index.html`，再把 `vtuber_art_new.psd` 拖进页面。

## 界面

右侧是 6 个选项卡，上次打开的会记住，Alt+1–6 可以直接切换：

| 选项卡 | 里面有什么 |
|---|---|
| 口型 | 载入配音、配音降噪、口型算法 / 灵敏度 / 降噪 / 防闪、麦克风、录一段 |
| 调节 / 动画 | 表情、嘴型、眼睛 / 左右耳 / 胡子、手势（左右分组）、手势专属动画、缩放框、电脑、动作、自动动画设置 |
| 输出 / 色彩 | 预览背景和参考视频、滤镜、曲线、导出 PNG 序列 |
| 骨骼 | 骨骼数值、骨骼关键帧、IK 拖动 |
| 关键帧 | 片段蓝图、关键帧列表、撤销、清空、保存 / 载入工程 |
| 图层 | 载入 PSD、图层检查 |

时间轴下面的播放栏里有两个全局开关：「◆ 自动记关键帧」和「插值」（新记的骨骼 / 缩放框关键帧用哪种曲线）。

## 做一条动画

1. **载入配音**：拖进 wav/mp3（建议从达芬奇导出整条配音轨，时间从 0 开始）。载入后会自动分析口型，时间轴上出现彩色口型条。
2. **试看**：直接点按钮、按键盘、拖骨骼，效果马上出现，但**不会被导出**，左上角会显示「试看中」，点「清除试看」恢复。
3. **录制**：勾上「录制按键」（或按 Enter），按空格播放，跟着配音按表情、手势、动作。每次按键都会在当前时间记一个关键帧。暂停状态下按按钮，也会在当前时间点记关键帧，可以一帧一帧摆。录制时拖骨骼、拖缩放框也会直接记关键帧。
4. **修改**：在「关键帧」面板里改时间、删除，或者撤销上一个；骨骼和缩放框的关键帧在各自的面板里改。点「保存工程」存成 json，下次拖进来接着改（先载音频再载工程）。
5. **导出**：设好范围，点「导出 PNG 序列」并选一个空文件夹。导出的文件夹里有：
   - `avatar_00000.png …`：透明背景的序列帧，达芬奇里可以直接当作一段素材导入
   - `转MOV_ProRes4444.cmd`：双击后转成带透明通道的 `avatar_prores4444.mov`，用的是系统里的 ffmpeg
   - `project.json`：这次的关键帧、骨骼轨道和口型，留给达芬奇 MCP 读

合轨的时候，把配音和这段动画放在同一个起点上就能对齐。

## 手势

左右手各选一个，同一边互斥；双手手势两边都占。再点一次已经亮着的手势就放下，「全部放下」一次清空。「左 / 右」一律指**画面上**的左右（角色面朝画面左边，所以画面左手是角色的右手）。

| 分组 | 手势 |
|---|---|
| 画面左手 | 竖手指、指天、请看、指右边、爪爪1、爪爪2、指后面 |
| 画面右手 | 摸下巴、指左边 |
| 双手 | 展示手、期待手、比心手、双手合十、抱臂、双爪、点赞 |

- **指后面**（图层 6）是手臂和衣服画在一起的那张图，它算画面左手，也参与互斥：选了指后面，原来的左手手势会放下；指后面时身体用这张图，不再画普通身体。手臂部分可以单独动（指指、缩放框），衣服不动。
- **身体方向跟手势走**：期待手、摸下巴会自动换成身体镜像版（图层 7），其他用正常身体（4/5 双层抖动）。
- **专属动画**：每个手势可以有 0 到多个，只在「手势专属动画」里列出现在举着的手势的：

| 手势 | 专属动画 |
|---|---|
| 展示手 | 托举、递出 |
| 竖手指 | 摇手指、戳戳 |
| 指天 | 指指天 |
| 请看 | 请看、指指点点 |
| 指右边 / 指左边 | 指指点点 |
| 爪爪1 / 爪爪2 | 挥手。顺时针摆时显示爪爪2，逆时针摆时显示爪爪1；全局「摇身」也按这个方向换帧。 |
| 指后面 | 指指：连续点两下，第二下稍轻 |
| 期待手 | 期待抖 |
| 摸下巴 | 摸下巴 |
| 比心手 | 晃晃（左右摆到尽头时轻轻放大） |
| 双手合十 | 拜一拜、搓手 |
| 抱臂 | 哼 |
| 双爪 | 挠挠、扑 |
| 点赞 | 点赞 |

  动作里的「挥手」（V 键）会临时用爪爪挥手。

### 缩放框（节目效果）

把手势超级拉长 / 压扁，并且可以把 PS 自由变换那种框也画进画面里。所有手势默认关闭。

- 选一个手势，横向 / 竖向缩放可以随便填（负数是翻转），也可以勾「在画面上拖」，直接拖预览上蓝色虚线框的 8 个手柄；按住 Shift 拖角上的手柄是等比。
- 锚点：手腕（从手腕往外拉长，默认）或中心。
- 「显示框（会导出）」：勾上后黑色的变换框会画进画面、跟着导出；不勾的话只有缩放效果，蓝色虚线框只在预览里编辑时出现。
- 这些都记在关键帧里，可以做「拉长 → 弹回去」：比如 4s 记一个 1×1，4.4s 记一个 0.8×2.6 并选「弹性阻尼」插值。

### 电脑和 WASTED

电脑托在展示手上，跟着展示手动（「托举」会把电脑一起举起来）。屏幕有白屏、FINAL、绿幕（纯绿 #00ff00，边缘保留了抗锯齿，达芬奇里抠掉绿色再垫画面）。位置和大小在「调节 / 动画」里调，会存进工程。导出底色别选绿幕，不然整张图都是绿的。

「WASTED 字」是头顶的那行字，打开的瞬间会从 1.8 倍砸下来。

旧工程（老 PSD 做的）载入时，电脑位置会自动换算到新 PSD 上；旧的「敲电脑」读成「展示手 + 白屏」，「FINAL 字」读成 FINAL 屏，旧的「身体偏移版」关键帧会被忽略。

## 骨骼

骨骼树：**身体 → 头 → 左耳 / 右耳**。程序动作（呼吸、跳、点头、摇头、歪头、摇身、发抖、抖耳朵……）和手势专属动画都写成对骨骼的增量，以后要调幅度改 `motion.js`。

- **骨骼选项卡**会在预览上画红线（选中的那根是黄色），红线不会导出；想在别的选项卡也看到，勾「其他选项卡也显示骨骼」。
- **数值**：每根骨骼有角度、X、Y、横缩放、竖缩放，叠在程序动作上面：角度和位移相加，缩放相乘。
- **在画面上拖**：
  - 拖红线末端的白圈：转动骨骼。
  - IK 链长 2 时，拖耳朵尖主要转耳朵，头只跟着偏一点；拖头顶会带一点身体。
  - 按住 Shift 拖关节（实心点）：平移这根骨骼。
- **关键帧**：「◇ 记关键帧」把当前数值记在当前时间（已经有就变成「◆ 更新关键帧」）；勾着「自动记关键帧」或者在录制时，拖动和改数值会直接记。时间轴最下面一行的菱形是骨骼（红，选中的黄）和缩放框（蓝）的关键帧。
- **插值**：每个关键帧记的是「从上一个关键帧到这一个」用哪种曲线：缓动（默认）、三次、线性、弹跳、弹性阻尼、阶跃。在关键帧列表里可以逐个改。
- **第一个关键帧之前是默认值**（骨骼归零、缩放框关闭），最后一个之后保持最后一个的值。想慢慢过渡，就先在起点记一个关键帧。

手势的画面拖拽与轨道示例见 [Agent1 缩放框使用指南](AGENT1-hand-transform.md)。

## 片段蓝图

把时间轴上一段的关键帧记成一份「蓝图」，可以整段部署到别的时间，也可以复制 JSON 交给 agent 参考或修改。

1. 在时间轴上**按住 Shift 拖**出一段（绿色区域），或者在「关键帧」选项卡里填起止时间。
2. 起个名字，点「记录选区」。蓝图存在浏览器里，换工程也在。
3. 每个蓝图可以：
   - **部署到当前时间**：把整段贴到播放头的位置。
   - **下载**：存成 json。
   - **复制**：复制 JSON，直接贴给 agent。
   - **删除**。
4. 「部署前清空目标区间」会先删掉目标时间段里原有的关键帧；「带上起始状态」会在开头补上录的时候那一刻的表情、耳朵、手势、电脑等状态，部署过去和原来看起来一样。
5. 别人（或 agent）改好的蓝图 json，用「导入蓝图」或者直接拖进页面就能加进列表。

蓝图格式（`type: "avatar_blueprint"`）：

| 字段 | 内容 |
|---|---|
| `name` / `duration` | 名称、长度（秒） |
| `source` | 从哪段记的：`t0`、`t1`、配音文件名、PSD |
| `startState` | 片段开头的状态：表情、眼睛、两只耳朵、胡子、嘴、`hands: {L, R}`、电脑、WASTED |
| `events` | 离散关键帧 `{t, k, v}`，t 是相对片段开头的秒数。k 有：`expr` 表情、`eyes`、`ears` / `earL` / `earR`、`whiskers`、`mouth`（null = 自动）、`hand`（打开手势）、`handOff`（放下手势，`all` = 全部）、`gact`（手势专属动画，`手势:动画`，比如 `pray:bow`）、`act`（全局动作）、`laptop`、`wasted` |
| `tracks` | 插值轨道：`bone.<body/head/earL/earR>` 的值是 `{x, y, rot, sx, sy}`；`hand.<手势>` 的值是 `{x, y, sx, sy, box, anchor}`。每个关键帧 `{t, v, ease}` |
| `summary` | 给人和 agent 看的一行一句的说明 |

手势、表情、动作、动画的 id 都在 `rig.js`（`HANDS`、`EXPRESSIONS`、`EYES`、`MOUTHS`）和 `motion.js`（`ACTIONS`、`HAND_ANIMS`）里。

## 实时麦克风

麦克风只能在 serve.ps1 开的 `http://localhost:8765/` 页面里用，第一次会弹窗问权限。

- **开麦克风**（按钮或 M 键）：说话时嘴型实时跟着动，表情、动作按键照常用。旁边的小条是音量，颜色是当前口型。有多个麦克风时在下拉框里选。开头几秒在适应你的音量和音色，说几句就准了。
- **录一段**：时间轴从 0 开始走，这期间按的表情、动作自动记成关键帧（不用勾「录制按键」）。再点一次停止，录音会自动变成配音轨，并重新做一遍完整的口型分析。之后跟载入配音文件一样，可以回放、改关键帧、导出。
- **录音文件**：点「保存当前配音 wav」可以单独下载；导出 PNG 序列时，这段 wav 也会一起写进导出文件夹，拿去达芬奇当配音轨，和动画从同一个起点放就是对齐的。
- **口型的取舍**：录音时看到的是实时口型，会晚一点；最终导出用的是停止后的离线分析，更稳、不会闪。
- **回放**：麦克风开着时，播放已有配音仍然按配音的口型；只有暂停或者在录音时，才跟麦克风走。
- **耳机**：录的时候建议戴耳机，避免喇叭的声音被录进去。浏览器的回声消除和自动增益已经关掉了，降噪保留开着。

## 降噪 / 嘴型闪

都在「口型」选项卡里：

- **口型降噪**（默认开）：分析口型前先估出噪声谱减掉，再用人声频段（250–4000Hz）的信噪比判断有没有在说话，风扇轰鸣、电流哼声基本不会让嘴乱动。实时的噪声每 1.5 秒自动重估，开麦后先安静一秒，状态栏显示「估噪中」时别说话。
  - **强度**：越大减得越狠，但人声小的字也可能被当成噪声。
  - **防闪**：越大嘴型越稳，但换口型会慢一点（默认约 90ms）。
  - **灵敏度**：说话时嘴不动（漏字）就往右拉；不说话时嘴还在动就往左拉。
- **配音降噪**：「降噪当前配音」把当前配音过一遍降噪（风扇、底噪、电流声这类持续的噪声），处理后的音频直接替换成配音轨，口型也重新分析；再点一次「还原原声」。「压低」是噪声最多压低多少 dB，默认 15，太大人声会发闷、有“水声”。勾着「录完自动降噪」时，麦克风录的每一段都会自动降噪。
  - 键盘声、说话声这类突发的声音减不掉。

## 口型规则

- 没说话时，用当前表情自带的嘴（比如「得意」是波浪嘴）
- 说话时用自动口型：信噪比判断有没有在说话，共振峰判断元音，映射到 a / o / e / i / u；刚停下的一小会儿算 bf（b/p/m 闭嘴）；s/sh/x 这类擦音（高频多）算 i（露牙）
- 手动选的嘴型优先级最高，会盖过上面两种
- 口型太碎或者太迟钝，就调「灵敏度」后点「重新分析口型」；声音很杂的时候可以改成「只看音量」

## 滤镜 / 曲线

只调虚拟形象这一层，不影响透明度。改动马上在预览里生效，勾着「导出时套用」时导出的 PNG 也会带上，存工程时会一起保存。

- **滤镜**：原图、鲜明（暖 / 冷）、戏剧（暖 / 冷）、单色、银色调、黑白、复古褪色、赛博。「戏剧」仿的是 iOS 的 Dramatic：压暗一点、加强中间调对比、降一点饱和度。「滤镜强度」可以在原图和滤镜之间调。
- **曲线**：RGB / 红 / 绿 / 蓝四个通道，后面是当前画面的直方图。点空白处加点，拖动调整；双击、右键或者把点拖出框外就删掉；两端的点只能上下动。曲线叠在滤镜后面生效。
- **对比**：按住 `\` 键或者「按住对比」按钮，看调色前的原图。
- **参考视频也套用**：只影响预览里的参考视频，方便看虚拟形象和视频的色调搭不搭；视频本身还是在达芬奇里调。

## 自动的小动作

在「自动动画」里可以开关：双层线稿每秒交替 8 次（线稿抖动）、整体微抖、呼吸（身体起伏、头和耳朵轻轻晃）、自动眨眼（正常 / 向左看 / 生气 / 星星眼 / 半睁才会眨）、耳朵偶尔抖一下（左右耳独立触发，按竖耳、歪耳、飞机耳、歪耳、竖耳的顺序甩动；歪耳状态只在歪耳和飞机耳之间切换）、说话时随音量轻晃头。自动甩耳会带动对应一侧的耳骨，在 0.25 秒内回弹。「律动」默认开启，开启后头和身体每拍上下弹一次，身体两拍完成一次左右摇摆。播放栏的全局速度可调 30–300 BPM，默认 120 BPM。动作和手势动画也跟随这个速度；挥手每两拍往返一次，双爪挠挠每拍四次。关闭身体律动仍会按 BPM 播放动作。关键帧的起点由时间轴决定。导出时这些动作每次都一样，同一个工程导两遍结果相同。

「说话时随音量轻晃头」根据配音或麦克风的人声音量，轻微抬头和左右摆动，不追踪真人头部，也不识别语气。手动锁定嘴型时不触发。关闭后自动口型、手动动作以及独立的呼吸 / 轻微晃动仍正常生效。

## 限制

- 只支持 8 位 RGB 的 PSD，不支持 PSB 和图层蒙版
- 口型分析不认字，只看声音；元音之间的过渡靠平滑处理，口型精确到大约 70ms
- 骨骼只有身体、头、两只耳朵；手势跟着身体走，自己的动作写在专属动画里，还没有手臂骨骼
- 指后面的手臂转得太多时，手臂和衣服的接缝处会露出来，「指指」只沿手臂方向轻微伸展
- 要选导出文件夹，得用 Edge 或 Chrome；别的浏览器会改成下载一个 zip

时间轴的「关键帧吸附」默认开启。拖动播放头、框选时间段或记录动作与骨骼关键帧时，会吸附到附近已有的关键帧，可在播放栏关闭。自动抖耳和眨眼在整拍触发，抖耳周期按 120 BPM 标定并取最近的 1/8 拍。

播放栏可设置输出起点和终点（秒），项目保存这两个值。区间外的关键帧仍可编辑。时间轴纵向滚轮以鼠标为中心缩放，横向滚轮、中键拖动或 Shift+滚轮平移，Home 适配全部。空格播放/暂停，左右方向键逐帧，上下方向键跳到后一个/前一个关键帧，Shift+左右方向键跳到输出起点/终点。
